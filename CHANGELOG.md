# Changelog

## v1.0.0 — Community Edition · Initial public version

- Offline IMAGEWTY logo editor for supported `0x300/0x403` layouts, designed to leave all unrelated firmware content untouched.
- English default, Spanish and simplified Chinese; selectable Dark/Light theme.
- Composition controls: preserve aspect ratio, crop or stretch, 10–200% scale, nine-point alignment, X/Y offsets, and solid/gradient/image backgrounds.
- Side-by-side display of selected image and original boot logo; live canvas and closable encoded-JPEG preview.
- Verification against supported structural rules, checksums, JPEG profile and allowed binary regions, plus external **Verify Firmware** comparison.
- Choose output filename once; use native Save As when supported or in-app name dialog otherwise.
- Simplified Next Steps and About. The tool does not install firmware and is not affiliated with device manufacturers.
- Refined multilingual layout so translated X/Y labels fit within their panel at tested widths, with added spacing before position actions.

**Release gate:** This package is a local **v1.0.0 candidate pending final Windows user acceptance**; it has not been publicly published at the time of packaging.
